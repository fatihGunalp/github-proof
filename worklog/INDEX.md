## Legend

```text
Result   status + one-line outcome only; full narrative lives in the session file
Route    model / effort actually used
Base     session base HEAD (verified from Git at session start)
Commit   final integrated commit, recorded from Session 111 onward.
         `—` on earlier rows means "not recorded here", not "no commit";
         locate it with `git log <Base>..` plus the linked session file.
```

```text
IN_PROGRESS = active meaningful development work
PASS        = goal completed and validation passed
PARTIAL     = meaningful progress, but goal not complete
BLOCKED     = needs a user decision, dependency, or external change
FAILED      = implementation or required validation failed
DOCS        = documentation or working-contract work only
```

Rows written before Session 113 also carry two pre-existing variants, kept as
recorded rather than restated: `PASS WITH FINDINGS` (goal met, review findings
closed in-session or explicitly deferred) and `PASS / COMPLETE` (a PASS that
also closed its slice). New rows use the six values above.
